Ladders

A Ladder plays every new commit of a branch against one fixed anchor commit, for a fixed number of games. So its line shows whether the patches that passed their SPRTs one by one also add up. It looks at its branch every few hours, on every push that Github announces, and after every MERGE Node into the branch.
